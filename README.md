# java-calculator-precourse

---
##  기능 요구 사항

- 입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.
- 쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 전달하는 경우 구분자를 기준으로 분리한 각 숫자의 합을 반환한다.
- 커스텀 구분자를 지정할 수 있다.  
  문자열 앞부분의 `"//"`와 `"\n"` 사이의 문자를 커스텀 구분자로 사용한다.
- 잘못된 입력이 들어올 경우 `IllegalArgumentException`을 발생시키고 프로그램은 종료된다.

---

##  구현할 기능 목록

### 입력 처리
- [ ] 사용자가 입력한 문자열을 전달받는다.
- [ ] 빈 문자열(`""`) 입력 시 `0`을 반환한다.
- [ ] 입력이 `null`이거나 비정상적인 경우 `IllegalArgumentException`을 발생시킨다.

### 구분자 처리
- [ ] 기본 구분자(쉼표 `,`, 콜론 `:`)를 기준으로 숫자를 분리한다.
- [ ] 커스텀 구분자(`"//[구분자]\n"`)가 지정된 경우 해당 구분자를 사용한다.  
  예: `"//;\n1;2;3"` → 구분자 `;`
- [ ] 여러 구분자가 혼합된 경우도 정상적으로 처리한다.

### 계산 로직
- [ ] 분리된 문자열을 정수로 변환한다.
- [ ] 모든 숫자의 합을 계산해 반환한다.

### 예외 처리
- [ ] 음수가 포함된 경우 `IllegalArgumentException` 발생 후 프로그램 종료.
- [ ] 숫자가 아닌 문자가 포함된 경우 예외 발생 처리.

### 출력
- [ ] 계산 결과를 `결과 : <합계>` 형태로 출력한다.

### 테스트
- [ ] 빈 문자열 입력 시 결과가 0인지 테스트한다.
- [ ] 쉼표/콜론 구분자 입력 시 합계가 올바른지 테스트한다.
- [ ] 커스텀 구분자 입력 시 합계가 올바른지 테스트한다.
- [ ] 잘못된 입력(음수, 문자 등) 시 예외가 발생하는지 테스트한다.

### 고민한 점
**커스텀 구분자의 허용범위**
* 커스텀 구분자의 허용 범위를 단일 문자로 제한할지, 임의 길이 문자열까지 허용할지 고민이 되었습니다.
  사용성을 고려해 임의 길이를 허용하되 기본 구분자와 혼용 가능한 정규식을 구성했습니다.

**클래스의 책임분리**
* 기존에는 StringAddCalculator 클래스가 문자열 파싱, 유효성 검증, 합계 계산까지 모든 책임을 맡고 있어 변경과 테스트가 어렵다고 느껴졌습니다.
  이를 개선하기 위해 기능별로 책임을 분리하여 ExpressionParser, NumberConverter, Adder 세 클래스로 세분화하였고, StringAddCalculator는 이 객체들을 조합해 전체 흐름을 제어하는 역할만 수행하도록 리팩터링했습니다.
  그 결과 단일 책임 원칙(SRP)을 준수하면서 코드 구조가 명확해지고, 테스트 용이성과 유지보수성이 향상되었으며, 변경에 따른 영향 범위도 최소화되었습니다.
