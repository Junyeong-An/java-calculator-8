# java-calculator-precourse

---
##  기능 요구 사항

- 입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.
- 쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 전달하는 경우 구분자를 기준으로 분리한 각 숫자의 합을 반환한다.
- 커스텀 구분자를 지정할 수 있다.  
  문자열 앞부분의 `"//"`와 `"\n"` 사이의 문자를 커스텀 구분자로 사용한다.
- 잘못된 입력이 들어올 경우 `IllegalArgumentException`을 발생시키고 프로그램은 종료된다.

---

##  구현할 기능 목록

### 입력 처리
- [ ] 사용자가 입력한 문자열을 전달받는다.
- [ ] 빈 문자열(`""`) 입력 시 `0`을 반환한다.
- [ ] 입력이 `null`이거나 비정상적인 경우 `IllegalArgumentException`을 발생시킨다.

### 구분자 처리
- [ ] 기본 구분자(쉼표 `,`, 콜론 `:`)를 기준으로 숫자를 분리한다.
- [ ] 커스텀 구분자(`"//[구분자]\n"`)가 지정된 경우 해당 구분자를 사용한다.  
  예: `"//;\n1;2;3"` → 구분자 `;`
- [ ] 여러 구분자가 혼합된 경우도 정상적으로 처리한다.

### 계산 로직
- [ ] 분리된 문자열을 정수로 변환한다.
- [ ] 모든 숫자의 합을 계산해 반환한다.

### 예외 처리
- [ ] 음수가 포함된 경우 `IllegalArgumentException` 발생 후 프로그램 종료.
- [ ] 숫자가 아닌 문자가 포함된 경우 예외 발생 처리.

### 출력
- [ ] 계산 결과를 `결과 : <합계>` 형태로 출력한다.

### 테스트
- [ ] 빈 문자열 입력 시 결과가 0인지 테스트한다.
- [ ] 쉼표/콜론 구분자 입력 시 합계가 올바른지 테스트한다.
- [ ] 커스텀 구분자 입력 시 합계가 올바른지 테스트한다.
- [ ] 잘못된 입력(음수, 문자 등) 시 예외가 발생하는지 테스트한다.
